Proyecto: Clasificación de Dígitos Manuscritos con TensorFlow y MNIST

Descripción:
Este proyecto fue realizado como parte de un proceso de aprendizaje personal, siguiendo el contenido del video educativo disponible en YouTube:  
https://www.youtube.com/watch?v=aFZEvQDTSyA&list=PLZ8REt5zt2Plph03SfZKijMWB68FUYfNc&index=3

El código implementa una red neuronal simple en TensorFlow para clasificar imágenes del dataset MNIST. A lo largo del notebook se incluyen explicaciones detalladas, comentarios pedagógicos y visualizaciones simbólicas para facilitar la comprensión de cada etapa del flujo de trabajo.

Objetivo:
Aprender los fundamentos del aprendizaje automático supervisado, el uso de TensorFlow y Keras, y la visualización de resultados en tareas de clasificación.

Características principales:
- Carga y exploración del dataset MNIST
- Normalización de imágenes
- Definición de una red neuronal secuencial con capas densas
- Entrenamiento del modelo con optimizador Adam
- Evaluación del rendimiento sobre datos de prueba
- Visualización de predicciones con colores simbólicos (azul = correcto, rojo = incorrecto)
- Gráficos de barras que muestran la distribución de probabilidades por clase

Requisitos:
- Python 3.x
- TensorFlow
- TensorFlow Datasets
- NumPy
- Matplotlib
